# Public API Resource Explorer

A beautiful interactive web page showcasing a curated list of free public API resources.

🔗 **GitHub Repository**: [https://github.com/mkhsu2002/Free_API_LIST](https://github.com/mkhsu2002/Free_API_LIST)

## Features

- 📊 **Data Visualization**: Uses Chart.js to display API category distribution and authentication statistics
- 🔍 **Smart Search**: Real-time search and multi-dimensional filtering capabilities
- 📋 **Structured List**: Google Sheets-like structured view
- 📥 **Data Export**: Supports CSV format export
- 📱 **Responsive Design**: Perfect adaptation to various device sizes
- 🎨 **Modern UI**: Beautiful interface built with Tailwind CSS
- 🌐 **Multi-language Support**: Switch between Traditional Chinese and English

## Tech Stack

- HTML5
- Tailwind CSS (CDN)
- Chart.js
- Font Awesome
- Google Fonts (Noto Sans TC)

## Deployment

### GitHub Pages Auto Deployment

1. Upload this project to a GitHub repository
2. Go to repository Settings > Pages
3. Select Source as `main` (or `master`) branch
4. Select `/ (root)` folder
5. Click Save, GitHub Pages will automatically deploy

After deployment, your website will be accessible at:
```
https://mkhsu2002.github.io/Free_API_LIST/
```

🌐 **Live Preview**: [https://mkhsu2002.github.io/Free_API_LIST/](https://mkhsu2002.github.io/Free_API_LIST/)

## Local Development

Simply open `index.html` in your browser to preview.

The website supports two languages:
- **Traditional Chinese (繁體中文)** - Default
- **English (English)** - Click the language switcher in the header

Language preference is saved in your browser's localStorage.
